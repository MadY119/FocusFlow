# ⏱️ FocusFlow - Pomodoro Sanctuary (Day 4/30)

Hey there! 👋 This is Day 4 of my personal challenge to build 30 Projects in 30 Days. 

For today's project, I built FocusFlow, a beautifully designed Pomodoro timer and productivity dashboard. The goal was to create a "Personal Sanctuary"—a serene, distraction-free environment for deep work, combining task management with time tracking and visual analytics.

## 💡 What it does
* Dynamic SVG Timer: A fully functional Pomodoro timer with a smooth, animated circular progress bar. Features Focus, Short Break, and Deep Focus modes.
* Kanban-Style Task Manager: Add daily intentions and track them across "To Do", "In Progress", and "Completed" columns.
* Dashboard & Analytics: Automatically tracks total focus hours, completed tasks, and calculates your daily streak. Features a dynamic bar graph reflecting your activity.
* Zen Breathing Widget: A CSS-animated breathing visualizer (ping & pulse effects) to help center the mind before starting a deep work session.
* Multi-View Routing: Seamlessly switch between Dashboard, Timer, Calendar, Tasks, and Archive views without reloading the page using Vanilla JavaScript.
* Local Persistence: All tasks, statistics, and streaks are safely stored in the browser's LocalStorage.

## 🛠 Tech Stack Used
* HTML5 & CSS3 (Tailwind CSS)
* Vanilla JavaScript (DOM Manipulation, SVG Animation, Intervals, LocalStorage API)
* Custom Fonts: Libre Caslon Text & Manrope
